# The bar: code change

## What it's for

A change other people will build on, merged without someone having to clean up after it.

## Checks

- [ ] The project's tests pass (run them; paste the summary).
- [ ] The linter and type checker pass, if the project has them.
- [ ] A test covers the new behaviour, and it fails without the change.
- [ ] The change does only what was asked: no unrelated edits.
- [ ] No secrets, debug prints or commented-out code left in.
- [ ] Names and style match the code around it.

## Never

- A test skipped or deleted to make the suite pass.
- "It should work" without having run it.
